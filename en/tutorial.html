EMQX 5.8.9 安裝與整合指南

把 EMQX 變成可用的 IoT 訊息中樞

從安裝 Woow EMQX add-on 開始，建立 MQTT 心智模型，接著走過驗證與 ACL、Listeners 與 TLS、Rule Engine、Connectors／Sinks 與 Home Assistant 整合，再到監控、備份與安全部署。22 章逐步引導，把開源 EMQX 5.8.9 打造成可靠的 IoT 訊息骨幹。銷售手冊、AI 提示詞庫與 Skill 手冊在 資源總覽。

基礎：認識與安裝

01

認識 EMQX 與 MQTT Broker

從 MQTT broker 的角色出發，看懂 EMQX 與 Mosquitto 的差異、架構與 Dashboard 全貌。

 02

安裝 Woow EMQX add-on

加入 repository、安裝、host_network 與五個連接埠，啟動後首次登入並改掉預設密碼。

 03

EMQX Dashboard 導覽

認識 EMQX Dashboard 的側欄模組、Overview 監控、語言與版本資訊。

 04

MQTT 心智模型

broker、client、topic、QoS、retained、will、keepalive、session 與共享訂閱，一次建立心智模型。

核心：連線與存取控制

05

建立第一個 MQTT 連線

用內建 WebSocket 工具 publish／subscribe，驗證 QoS，建立第一個 MQTT 連線。

 06

Authentication 驗證

Password-Based 內建資料庫、建立使用者、JWT 與 HTTP/LDAP 概念，守住連線入口。

 07

Authorization 與 ACL

授權順序、內建 ACL、主題規則配對與拒絕策略，與驗證搭配做最小權限。

 08

Listeners 與 TLS

1883／8083／8084／8883、新增修改 Listener、TLS 憑證與 mTLS，處理連接埠衝突。

進階：規則、整合與資料橋接

09

Rule Engine 規則引擎

SQL 的 SELECT／FROM／WHERE、事件與 topic 作為 source、內建函數，寫出第一條規則。

 10

內建動作與訊息轉發

console output、republish、重寫 topic，把規則命中轉成實際動作。

 11

Connectors 與 Sinks

Webhook、HTTP、Kafka、PostgreSQL／MySQL 的 Connector 與 Sink，以 Webhook／HTTP 實作。

 12

Sources 與資料匯入

MQTT 事件 source、跨 broker 橋接概念、訊息回寫 EMQX。

 13

與 Home Assistant 整合

HA MQTT 整合、discovery、birth／will、狀態主題、Zigbee2MQTT 與 Mosquitto 遷移。

維運：監控、管理與復原

14

客戶端與訂閱管理

Clients 清單、踢除、統計、Subscriptions、慢訂閱與主題監控。

 15

監控與 Metrics

Dashboard 統計、節點狀態、系統資源、Prometheus 與速率指標。

 16

訊息與主題管理

Message publish、retained 管理、主題樹、Topic Metrics 與延遲發布。

 17

設定與組態

Dashboard 設定、EMQX_ 環境變數、設定檔與 Secret 管理。

 18

Log、API 與診斷

Log & Trace、診斷工具、REST API 概念與 Health Check。

 19

ngrok TCP 通道

add-on 專屬的 ngrok TCP 1883 通道、authtoken、固定位址與安全風險。

 20

備份、還原與更新

資料範圍、驗證／ACL／橋接備份、還原、更新與 Mosquitto 遷移。

 21

安全部署

host_network 風險、對外暴露、Rate Limit、TLS 要求與最小權限。

 22

完整疑難排解

無法啟動、無法連線、Dashboard 進不去、連接埠衝突、資源不足、驗證失效的診斷與修復。
